# sie4ka — портфолио и маленький иллюстрированный уголок

Статический сайт на HTML, CSS и JavaScript без сборки и фреймворков. В проект включены единый лендинг: резюме, опыт, образование, контакты и мемная галерея в самом конце. Визуальная идея — уютный пастельный скетчбук, фотографии Анастасии и её рыжего кота, цветочные детали и авторская рисованная иллюстрация кота с коровкой.

## Файлы
- `index.html` — резюме и профессиональный опыт.
- `memes.html` — мемная галерея.
- `styles.css` — адаптивное оформление.
- `script.js` — мобильное меню и данные мемов.
- `assets/` — фотографии, иллюстрация и favicon.

## Как открыть
Распакуйте архив и откройте `index.html` в браузере. Для разработки можно открыть папку в любом редакторе кода. Сервер и установка зависимостей не нужны. Основные страницы и ресурсы используют относительные пути. Шрифты подключаются из Google Fonts при наличии интернета; при его отсутствии браузер использует запасной системный шрифт.

## Фото и иллюстрации
Замените `assets/portrait-anastasia.png` на новое фото, сохранив имя файла, либо обновите путь в `index.html`. Аналогично заменяется `assets/ginger-cat-photo.jpg`. Главная иллюстрация находится в `assets/hero-cat-cow.png`. Для замены изображения оставьте имя файла прежним или поменяйте путь в HTML. Загруженные фотографии использованы как есть; изображения мемов сохранены отдельными файлами в `assets/`.

## Как добавить мем
В `script.js` найдите массив `memes`. Добавьте объект вида:

```js
{
  image: 'assets/my-meme.jpg',
  title: 'Короткий заголовок',
  caption: 'Подпись к мему.',
  tag: 'рабочие будни'
}
```

Сначала положите изображение в `assets/`. Укажите осмысленный заголовок и альтернативный текст — сейчас `title` также используется как `alt` изображения.

## Мемная галерея
Мемы собраны в одной секции в самом конце главной страницы. Карточки используют изображения целиком, чтобы не обрезать надписи. Чтобы добавить мем, положите файл в `assets/` и добавьте объект в массив `memes` в `script.js`.

## Как добавить профессиональный кейс
Поскольку реальные публичные материалы пока не предоставлены, отдельная галерея кейсов не используется в текущей версии, чтобы не создавать впечатление выдуманных проектов. Когда появятся разрешённые к публикации обезличенные примеры, добавьте секцию в `index.html` с описанием задачи, личного вклада, инструментов и результата. Не публикуйте внутренние данные работодателя.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub и загрузите содержимое этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите публикацию из ветки `main` и папки `/ (root)`, затем сохраните.
4. После публикации откройте предоставленный GitHub Pages URL.

## Публикация на Netlify
Откройте Netlify, выберите ручное развёртывание (Deploy manually) и перетащите папку проекта. Сборка не нужна.

## Перед публикацией
- Проверьте контактные данные и даты.
- Убедитесь, что вы согласны публиковать личную фотографию и фото питомца.
